## 二、格式规则

### 1. 字段完全未改动

- 字段名、字段顺序、字段数量 **与原表逐字节一致**（已用 API 逐表比对，9/9 通过）
- **保留了原表的重复列名**：Sheet1 有 4 个图片相关列，其中列 17 和列 30 都叫 `照片url`，列 23 和列 31 都叫 `匹配照片url` —— 按你「不要修改字段」的要求，全部保持原名，未做任何重命名
- **保留了原表的空表头**：Sheet1 第 38 列为空，原样保留为空
- **保留了原表的特殊表头**：Sheet1 第 1 列原始内容为 `' 等'`（含前导空格），原样保留为 ` 等`

### 2. 图片列 → 相对路径

图片列的值已从飞书图片对象替换为相对路径：

```
images/20251001/central/00006_cur.jpg
images/20251001/central/00006_match.jpg
```

**全部为相对路径，无任何绝对路径。** 已全表扫描确认：绝对路径 0 个、反斜杠 0 个。

这意味着：
- 换电脑、换盘符、换目录，CSV 都不用改
- 只要 CSV 和 `images` 文件夹放在同一层，就能直接跑

### 3. 路径对应关系

```
你的目录/
├── images/
│   ├── 20251001/
│   │   ├── central/
│   │   ├── north/
│   │   └── ...
│   └── ...（31 个日期目录）
├── Sheet1.csv          ← 和 images 同级
├── 摆拍货架.csv
└── ...
```

路径规则：`images/{拜访日期}/{战区英文}/{序号}_{cur|match}.jpg`
- `cur` = 本次拍摄
- `match` = 匹配的历史照片

## 三、Sheet1 的图片列说明（重要）

原 Sheet1 有 **4 个图片相关列**，容易混淆：

| 列 | 表头 | 原内容 | 我的处理 |
|---|---|---|---|
| 17 | 照片url | `["N_202510_01_ac5a16a4..."]` | **保持原样**（这是图片编号文本，不是图片） |
| 23 | 匹配照片url | `["N_202509_11_a7eee94d..."]` | **保持原样**（同上） |
| 30 | 照片url | `{'fileToken': 'C7dgbfPtm...'}` | **→ 相对路径** |
| 31 | 匹配照片url | `{'fileToken': 'Fw67bouzQ...'}` | **→ 相对路径** |

只有列 30、31 是真图片，因此只转了这两列。列 17、23 是文本编号，是业务字段，原样保留。

> 之前的旧版本 CSV 把列 17/23 转了路径、列 30/31 留成了 `{'id': 1, 'type': 'embed-image'}` 乱码，这是错的，已修正。

## 五、使用建议

### 微调用法

CSV 已可直接用于多模态微调（如 LLaVA / Qwen-VL 格式）：

```python
import pandas as pd

df = pd.read_csv('Sheet1.csv')
# 图片列已是相对路径，拼上根目录即可
img = Image.open(df.loc[0, '照片url'])   # images/20251001/central/00006_cur.jpg
```

### 注意事项

1. **CSV 和 images 必须同级**，否则要改相对路径前缀
2. 文件为 UTF-8 with BOM 编码，Excel 打开不乱码
3. `照片url` 和 `匹配照片url` 在 CSV 里各出现两次（原表就这样），用 pandas 读取会自动变成 `照片url` / `照片url.1`，需要靠列位置区分
4. `人员信息.csv`、`Sheet3.csv` 没有图片，是参考表
