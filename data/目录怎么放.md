# 目录怎么放（最重要的一页）

## 一、核心原则：CSV 里的路径是「相对 CSV 自己」的

CSV 里存的是：

```
images/20251001/central/00006_cur.jpg
```

这是**相对路径**，意思是：

> 「从**我这个 CSV 文件所在的文件夹**出发，进去 `images`，再进去 `20251001`，再进去 `central`……」

所以 **`images` 文件夹必须正好在 CSV 的同一层**。多一层、少一层，全部路径都会失效。

---

## 三、三种常见错误（务必避开）

### ❌ 错误 1：images 多套了一层

```
data\
└── data\          
    └── images\     ← 这样 CSV 在 data 下就找不到 images 了
        └── csv
```

**原因**：解压 zip 时如果 zip 内部自带一层 `images\`，而你又解压到 `data\`，就会变成 `data\images\`，这是对的。但如果解压到 `data\巡店AI表格\` 就错了。

### ❌ 错误 2：CSV 和 images 分家了

```
D:\Users\Desktop\巡店AI\
├── data\
│   └── images\
└── 表格\              ← CSV 放这里，它去找 ../images 找不到
    └── Sheet1.csv
```

### ❌ 错误 3：解压出 `images\images\`

```
data\
└── images\
    └── images\      ← 多一层，路径全断
        └── 20251001\
```

**这是最常见的**。解压前先看一眼压缩包内容，确认是否自带 `images\` 前缀。

---

## 四、解压操作建议

### 图片（22 个 part 包 + 第 1 批）

1. 把**所有** `part*.zip` 都下载到同一个文件夹（比如 `data\_zips\`）
2. 解压时**全部解压到 `D:\Users\Desktop\巡店AI\data\`**
3. 解压过程会问「是否覆盖同名文件」→ **选「全部是」**
   - 两批之间有 1,622 张重叠，覆盖是正常的，内容一致
4. 解压完检查：`data\images\20251001\` 是不是直接就是 `.jpg` 文件
   - ✅ 对：`data\images\20251001\central\00006_cur.jpg`
   - ❌ 错：`data\images\images\20251001\...`
   - ❌ 错：`data\20251001\central\...`（缺 images 层）

### 表格 zip

直接解压到 `D:\Users\Desktop\巡店AI\data\`，CSV 就会落在 images 旁边。
（如果解压出的是一个文件夹名，把里面文件**拖出来**放到 data 根下。）

## 五、解压完跑一次自检

双击 `check.py`（或在 data 目录执行 `python check.py`），它会告诉你：

| 检查项 | 期望结果 |
|---|---|
| images 位置 | `[OK] 找到 images 文件夹` |
| 扫描张数 | `[OK] 扫描到 71320 张图片` |
| 文件夹张数 | `[OK] 237 个日期/战区文件夹 张数全部正确` |
| CSV 路径 | 每个 CSV 显示 `存在数 = 路径数，缺失 0，绝对路径 0` |
| 文件数量 | `[OK] 文件数量正好 71,320` |

**只要这 5 项全 OK，就说明目录放得完全正确，可以开始训练了。**

如果 `[!!]` 报错，把报错那几行发我，我帮你定位。

## 六、为什么不把 CSV 里的路径改成绝对路径？

你之前明确要求过「不能用绝对路径」，而且相对路径确实更好：

| 方式 | 换电脑 | 改文件夹名 | 移动到别的盘 |
|---|---|---|---|
| 相对路径 | ✅ 直接可用 | ✅ 直接可用 | ✅ 直接可用 |
| 绝对路径 | ❌ 全废 | ❌ 全废 | ❌ 全废 |

只要 CSV 和 images 保持**同级**这个关系，你整个 `data` 文件夹随便搬、随便改名、随便拷贝给别人，都能直接用。

---

## 七、快速自查口诀

> **「CSV 挨着 images，images 里面直接是日期，日期里面直接是战区，战区里面直接是 jpg」**

四句话对上，就不会错。
